Claude Code & VPS — Anwendungsfälle

Alles was ein Hetzner VPS und Claude Code gemeinsam leisten können — von MCP-Servern über automatische Syncs bis zu Multi-Agent-Pipelines.

Hetzner VPS × Claude Code

Was du mit einem
eigenen Server
alles machen kannst

Der Server ist das Rückgrat. Claude Code ist das Gehirn. Zusammen ersetzen sie ein ganzes Entwicklerteam — rund um die Uhr.

Alle Anwendungsfälle im Detail

🔌
MCP-Server hosten
aktiv auf deinem Server
  • Odoo: Kunden, Aufträge, Produkte abfragen
  • Shopify: Bestellungen, Artikel, Kunden
  • Eigene Datenbank als Claude-Tool
  • Google Sheets live auslesen/schreiben
  • Jede eigene API als MCP-Endpunkt
⌨️
SSH-Direktzugriff
Claude Code → Server
  • Python / Shell Scripts direkt ausführen
  • Server-Logs live lesen und analysieren
  • Dateien übertragen und verarbeiten
  • Services starten, stoppen, neu starten
  • Datenbanken direkt abfragen
⚡
Webhook-Empfänger
Event-getrieben
  • Shopify-Bestellung → Claude verarbeitet sofort
  • Neuer Odoo-Kontakt → ins Cockpit + Mail
  • GitHub Push → automatischer Code-Review
  • Formular-Einsendung → KI antwortet
  • Beliebige externe Events abfangen
🕐
Scheduled Cloud Agents
Cron-gesteuert
  • Stündlich: Odoo ↔ Cockpit synchronisieren
  • Täglich: Berichte generieren & mailen
  • Wöchentlich: Newsletter-Entwurf erstellen
  • Nächtlich: Datenbank aufräumen, Bilder verarbeiten
  • Monatlich: Umsatz-Analyse & Zusammenfassung
🖼️
Batch-Verarbeitung
Hintergrund, ohne Warten
  • Produktbilder: Hintergrund entfernen (rembg)
  • Bilder für Kanäle zuschneiden (Shopify, Etsy)
  • PDFs & Rechnungen automatisch generieren
  • Excel-Reports aus Rohdaten erzeugen
  • E-Mail-Kampagnen vorbereiten & versenden
🤖
Multi-Agent-Pipelines
Agenten koordinieren
  • Agent A sucht Leads → B recherchiert → C schreibt
  • Subagenten parallel starten & zusammenführen
  • Morgen-Briefing fasst alle offenen Punkte zusammen
  • Fehler-Monitor überwacht alle anderen Agents
  • Komplexe mehrstufige Workflows automatisieren
💾
Persistente Datenspeicherung
Sessions-übergreifend
  • Wissensbasis aufbauen die wächst
  • Aufgabenstatus über Sessions hinweg tracken
  • Ergebnisse dauerhaft speichern & abrufbar halten
  • Kontext-Datenbank für Agents
  • Eigene Vektordatenbank für Suche & RAG
🛠️
Eigene APIs entwickeln & hosten
Claude baut, Server hostet
  • Claude schreibt die API, Server läuft sie permanent
  • Cockpit-Features als eigene Endpunkte
  • Shopify → Odoo Bridge-API
  • Interne Tools ohne externe Abhängigkeit
  • Claude pflegt und erweitert den Code
🚀
Deployment & CI/CD
Code → Live
  • Claude schreibt Code → direkt auf Server deployen
  • Tests in echter Serverumgebung ausführen
  • Staging & Production trennen
  • Automatische Updates bei Git-Push
  • Rollback bei Fehlern automatisieren
📡
Monitoring & Alerting
Nie wieder selbst checken
  • Shopify-Shop: Fehler & Ausfälle sofort melden
  • Lagerbestand unter Schwelle → Alarm
  • Umsatz-Ausreißer erkennen & erklären
  • API-Fehler loggen und zusammenfassen
  • Wettbewerber-Preise täglich prüfen
📊
Daten-Sync & Integration
Systeme verbinden
  • Odoo ↔ MH-Cockpit: Kunden immer aktuell
  • Shopify ↔ Odoo: Bestellungen automatisch
  • Alle Systeme → Google Sheets als Übersicht
  • Webhook-Hub: empfängt von allen, verteilt an alle
  • Single Source of Truth für euer gesamtes Business
📄
Dokument-Automation
Ohne manuellen Aufwand
  • Angebote & Rechnungen automatisch generieren
  • Produktbeschreibungen über Nacht neu schreiben
  • Lieferscheine, Zertifikate aus Templates befüllen
  • Meetings transkribieren → Aufgaben extrahieren
  • Verträge aus Kundendaten befüllen
