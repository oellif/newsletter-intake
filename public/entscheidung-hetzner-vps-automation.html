1. Server-Wahl & Specs

CPX12 bei Hetzner (Nürnberg, Deutschland) — 1 vCPU AMD, 2 GB RAM, 40 GB SSD, Ubuntu 26.04. Kosten: €11,49/mo + €0,50 IPv4 = ~€11,99/mo flat. DSGVO-konform: EU-Anbieter, kein CLOUD Act, Daten bleiben in Deutschland. Keine Setup-Gebühr, sekundengenau abgerechnet.

2. Odoo MCP Server

mcp-server-odoo 0.7.1 (ivnvxd) läuft als systemd-Service mit Autostart. Verbindet Claude Code direkt mit Odoo wmfe über XML-RPC. Benutzer: Daniel Schuster (info@marktplatz-helden.at). Service ist aktiv und startet automatisch bei Server-Neustart.

3. Sicherheitsentscheidung SSH-Tunnel

Port 8080 ist nach außen gesperrt (UFW: nur Port 22 offen). Zugriff auf den MCP-Server läuft ausschließlich über SSH-Tunnel: odoo-tunnel.bat starten, dann verbindet Claude Code auf localhost:8080. Vorteil: Keine Angriffsfläche, kein offener Port, Odoo-Zugriff nur für authentifizierte SSH-Verbindungen.

4. Geplante Verwendungszwecke

MCP-Server für Odoo (fertig) und Shopify (geplant), Webhook-Empfänger für Events aus Shopify/Odoo, Scheduled Cloud Agents (Cron-Jobs), Batch-Verarbeitung (rembg Bilder, PDFs, Reports), Multi-Agent-Pipelines, Daten-Sync Odoo↔Cockpit. Vollständige Übersicht: 12 Kategorien dokumentiert.

5. Odoo → MH-Cockpit Sync

Kunden aus Odoo sollen automatisch und immer aktuell im MH-Cockpit verfügbar sein — ohne manuellen Eingriff. Der Hetzner-Server kann direkt Odoo via XML-RPC abfragen und Daten in den Cockpit schreiben. Noch offen: Welche Daten genau (Kontakte, Aufträge?), wohin im Cockpit (Sheet, DB?), wie oft synchronisieren.

6. Nächste Schritte

Odoo→Cockpit-Sync konkretisieren (welche Daten, welches Ziel, welches Intervall), SSH-Key einrichten für Tunnel ohne Passworteingabe, weitere MCP-Server aufbauen (Shopify), Newsletter-Cron und Messe-Leadscan aufsetzen, rembg Bild-Batch einrichten.
